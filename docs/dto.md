# DTO


## Como realizar DTO
Acesso o aplicativo de checklist, siga o passo a passo 
1- Localize o módulo de segurança - 02 Selecione o DTO - 03 Selecione REALIZAR DTO - 4- Selecione o DTO que deseja
realizar- 5- Selecione: FILIAL GRUPO DTO TIPO DE DTO, 6- Selecione o colaborador e clique no “+” para adicionar. Podem ser adicionados até 3 colaboradores por DTO - 7- Inicie - 8- Após iniciar, marque com OK
ou NOK - 9- Em caso de NOK, se
tiver mais de um
colaborador, informe
qual deles recebe o nok Carregando o conteúdo para leitores de tela - 10- Informe a ação que será
realizada, obrigatório. Adicione fotos se desejar - 11- Revise as
respostas e finalize.
